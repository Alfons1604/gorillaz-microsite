# Gorillaz Microsite

Academic project for **Web Interfaces Design** (2nd year, Web Application Development, IES Zaidín-Vergeles).

A responsive, accessible one-page microsite about the band Gorillaz and their album *The Mountain* (2026), with five sections: Home, Biography, Albums, On Tour and Contact.

## Features

- Mobile-first layout with a hamburger menu below 900 px
- Album section with a featured release, a cover carousel and embedded videos
- Tour dates with an interactive map
- Contact form (client-side validation) and mini merchandise section
- Built with accessibility in mind (WCAG, Nielsen's heuristics)

## Tech

HTML5, CSS3 and vanilla JavaScript. Fonts: Roboto Condensed and Work Sans.
